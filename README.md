## 📌 Descripción del Proyecto

Aplicación web desarrollada en **Django 5** para la **Fundación Patrimonio Vivo**. El sistema permite catalogar, difundir y administrar espacios, monumentos y edificios de valor patrimonial en Chile (con énfasis en la Región de Valparaíso), ofreciendo un control de acceso basado en roles (RBAC) e integración con estilos responsivos mediante Bootstrap 5.
